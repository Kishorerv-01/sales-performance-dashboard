# Sales Performance Dashboard

An interactive sales analysis dashboard built using Google Looker Studio to analyze sales performance across months, cities, products, categories, and payment methods.

## Tools Used

- Google Looker Studio
- CSV
- Data Cleaning
- Data Visualization

## Key Performance Indicators

| KPI | Value |
|---|---:|
| Total Sales | 4,932,705 |
| Total Quantity | 3,045 |
| Total Orders | 1,000 |
| Average Order Value | 4,932.71 |
| Average Quantity Per Order | 3.05 |

## Key Insights

- Bangalore generated the highest sales among all cities.
- June recorded the highest monthly sales.
- Office Chair was the top-selling product.
- Home contributed the largest share of sales.
- Net Banking was the leading payment method.

## Dataset

The project uses a cleaned sales dataset containing information about orders, customers, products, cities, categories, payment methods, quantities, and sales.

## Project Objective

The objective of this project is to analyze sales data and create an interactive dashboard that helps identify sales trends, top-performing products, high-performing locations, customer purchasing patterns, and preferred payment methods.
